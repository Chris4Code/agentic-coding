# Special Use Cases chapter folder

Every chapter file added under `src/special-use-cases/` must also be linked from this folder's `README.md`, in addition to being linked from the root `src/SUMMARY.md` as usual. Otherwise the chapter won't be discoverable from this section's own overview page.

Each entry in the README.md list must include a short (one-sentence) description of the chapter, not just the bare link.
