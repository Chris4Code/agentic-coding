# Introduction

This book is a collection of study notes on **agentic coding** which means using AI agents to write, review, and maintain software. It synthesizes the research findings, contained in the `notes` folder, into a structured, clear reference. 99% of the text has been created using claude code based on these research findings.

## What this book covers

* [Basics](./basics.md) – core mechanics behind LLM inference and cloud usage, such as the KV cache and prompt caching.
* [Agentic Coding Harnesses](./agentic-coding-harnesses.md) – the tools that wrap an LLM into a working coding agent, and how harness responsibility splits between AI vendor and engineering team.
* [Local Models and Hybrid Cloud usage](./local-models.md) – running agentic coding setups on local hardware and inference engines, and combining them with cloud models in one workflow.
* [Hybrid Setups](./hybrid-setups.md) – concrete local/cloud architectures by user scale (single developer, small team, enterprise) and local hardware class.
* [Software Factories](./sw-factories.md) – opinionated AI-native software delivery systems maximizing human control while minimizing human efforts.
* [RAGs](./rags.md) – Retrieval-Augmented Generation architectures and LLM pipelines.
* [Quality](./quality.md) – aspects and methods of long term software quality assurance.
* [Security](./security.md) – isolating and governing what agents are allowed to do.
* [Cost Control](./cost-control.md) – tracking and managing the cost of agentic AI usage.
* [AI driven codebase rewrites](./ai-driven-codebase-rewrites.md) – using agents to assess and transform existing codebases.

A [Glossary](./glossary.md) at the end collects every term introduced across chapters, each with a short definition and a link back to where it's explained in detail.

## How this book is written

The chapters are a polished write-up layered on top of a separate body of raw research, which is treated as the source of truth for anything concrete: named tools, version numbers, benchmarks, pricing, and citation links. That research comes from two directions — notes written and curated by hand, and deep-research passes run by an AI agent against live web sources — and each topic can be revisited later, so a chapter's factual backing accumulates over time rather than being fixed at first draft.

Almost all of the prose is then generated by Claude Code from that research in structured editing sessions. Integrating new findings, restructuring a chapter, and tightening existing text are handled as deliberate passes that first preview the intended change and then resolve it into finished prose matching the chapter's established voice and sourcing rigor. A separate verification pass re-checks the concrete claims in a chapter against primary sources, correcting anything outdated and flagging, in a `Research Note:`, wherever a fact could only be partially corroborated.

Every research and editing pass is logged so that any figure or claim in the book can be traced back to the material it came from. Chapters that predate this process — drafted early from a single unverified research chat — are noted as such until a verification pass has been run over them.

For more details on these research & editing passes and for instructions on how to build the book locally, have a look into the `README.md` at the repository root.
